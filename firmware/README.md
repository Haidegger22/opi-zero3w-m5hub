# Прошивка для CardKB

`cardkb_m8.hex` — собранная прошивка для ATmega8 (наш экземпляр CardKB v1.1),
записывается в клавиатуру через ISP с Raspberry Pi 5 (см. [INSTALL.md](../INSTALL.md)).

## Что это за прошивка

Исходник — официальный, от M5Stack:

- репозиторий: https://github.com/m5stack/M5Unit-KEYBOARD
- файл: `examples/firmware/CardKB_Firmware/CardKB_Firmware.ino`
- лицензия: **MIT** (Copyright M5Stack)

Это не наша модификация: мы взяли официальный исходник как есть и собрали его под
ATmega8. Ценность именно в нём — он добавляет **режим сканирования нажатий**
(регистры `0x20` и `0x10`), из-за которого стрелки начинают держаться, пока
клавиша зажата. Со старой прошивкой клавиатура сообщала только отжатие.

## Характеристики сборки

| Параметр | Значение |
|---|---|
| Микросхема | ATmega8 (сигнатура `0x1e9307`) |
| Размер | 15 477 байт |
| Занято во флеше | 5 496 байт (70 %) |
| I2C-адрес | 0x5F (не изменился) |
| Тактирование | внутреннее 8 МГц |
| Совместимость | обратная: при режиме `0x00` ведёт себя как прежняя |

## Как собрать самому

```bash
# arduino-cli + ядро MiniCore (поддерживает ATmega8)
arduino-cli core install MiniCore:avr
arduino-cli lib install "Adafruit NeoPixel"

# сборка
arduino-cli compile \
  --fqbn MiniCore:avr:8:clock=8MHz_internal \
  --output-dir out \
  CardKB_Firmware/
# на выходе out/CardKB_Firmware.ino.hex
```

Проверялось на arduino-cli 1.5.1, ядро `MiniCore:avr@3.0.3`, библиотека
`Adafruit NeoPixel@1.15.5`.

## Про родную прошивку

Перед записью скрипт прошивки сохраняет то, что было в чипе, в `~/cardkb-original.bin`
(7432 байта). Этот файл в репозиторий не выкладывается: он принадлежит производителю,
а не нам. Откат выполняется тем же скриптом — просто передать ему этот файл.
